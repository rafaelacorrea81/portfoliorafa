## ➕ Como adicionar um novo projeto

1. Salve a imagem na pasta `img/`. Prefira `.jpg` ou `.png` com menos de 500 KB.
2. Abra o `script.js` e procure a lista `projetos`, no início do arquivo.
3. Coloque uma vírgula depois do último bloco e cole um novo bloco:

```js
{
  titulo: "Nome do projeto",
  categoria: "Social Media",
  imagem: "img/nome-da-imagem.jpg",
  descricao: "Breve descrição do projeto."
}
```

- Use `inteira: true` para imagens que não podem ser cortadas, como logotipos em fundo branco.
- Uma categoria nova vira um botão de filtro automaticamente.
- ⚠️ O GitHub diferencia letras maiúsculas e minúsculas: `Logotipo.png` e `logotipo.png` são arquivos diferentes.

## 🎨 Como mudar as cores

As cores ficam no início do `style.css`:

```css
:root {
  --azul: #5b6a9e;
  --azul-escuro: #414e80;
  --creme: #f1e0a6;
  --creme-claro: #f8efcf;
}
```

---

## 🚀 Como publicar no GitHub Pages

1. Envie todos os arquivos e a pasta `img/` para o repositório.
2. Vá em **Settings → Pages**.
3. Em **Branch**, escolha `main` e a pasta `/ (root)`, depois clique em **Save**.
4. Em alguns minutos, o site estará no ar no endereço mostrado na página.
